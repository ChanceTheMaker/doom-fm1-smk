Doom SMK Test01

Private SMK-37 Pro test. One silent test room, using the real Doom engine.

Doom has no USB updater. After installation the USB MIDI connection will disappear. Restoring synth firmware uses the XIAO SMK recovery adapter.

  • Use the same SMK-37 Pro whose backup this package was built from.
  • Start from updater-enabled Felucca, Sloop or Melodee SMK. Close other MIDI applications.
  • Keep power and USB connected throughout the transfer.
  • Lowest seven white keys: left, forward, right, back, fire, use, menu. Next four: enter, run, strafe left, strafe right.
  • PATCH opens the menu; PARA selects. Hold both OCT buttons for two seconds to request ROM recovery.
