Credits & licenses

Port, original campaign, sprites, original music, synthesized effects and website by Chance Roth (@ChanceTheMaker).

Engine and artwork

DoomGeneric builds on the Doom engine by id Software. Original engine notices are retained in the source. This project is distributed under GPL-3.0.

Miniwad, derived from Freedoom, supplies the starting open-content asset set. Copyright 2001–2018, Contributors to the Freedoom project. Read the retained BSD-style license. Our campaign modifies maps, textures and sprites; no commercial Doom WAD is required.

Enemy and weapon artwork and the classic HUD come from Freedoom v0.13.0. See the retained license and contributor credits.

Development preview

The title screen uses the classic DOOM logo, originally designed by Don Ivan Punchatz for id Software. The source image is credited to SteamGridDB; its checksum and conversion are recorded in the source repository. The logo and DOOM trademark belong to their owners and are not covered by the port's GPL or Freedoom licenses.

The browser simulator shares the native game engine and display assets. FM-1 controls preserve the earlier Doom simulator work; the SMK device layout adapts Sloop SMK under GPL-3.0. The WebAssembly build uses Emscripten; see its license. Browser performance does not establish hardware performance.

Music

“Circuit Breaker” is an original eight-bar heavy loop, composed and synthesized for this port. It uses no commercial Doom music or sampled audio. The score and synthesizer are GPL-3.0-only.

Hardware and updater

Based on Felucca by Leo Kuroshita (@kurogedelic), Hügelton Instruments, and the Felucca / Sloop / Melodee SMK hardware work. The dual-core audio worker and launch sequence adapt the Melodee SMK work. Original GPL notices and file provenance are retained. The browser fetches checksum-pinned base packages separately; the official FM-1 V15 restore file is bundled for convenience and remains M-VAVE firmware, outside the port’s GPL license. Private device dumps are never hosted here. Inherited JieLi SDK package components retain their Apache 2.0 notice.

The native build uses mpaland/printf under the MIT license, plus the separately installed JieLi compiler/runtime. See the repository for toolchain and source provenance.
