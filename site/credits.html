Hardware and updater

Based on Felucca by Leo Kuroshita (@kurogedelic), Hügelton Instruments, and the Felucca / Sloop / Melodee SMK hardware work. Original GPL notices and file provenance are retained. The browser fetches checksum-pinned base packages separately; vendor packages and private device dumps are not hosted here. Inherited JieLi SDK package components retain their Apache 2.0 notice.

The native build uses mpaland/printf under the MIT license, plus the separately installed JieLi compiler/runtime. See the repository for toolchain and source provenance.
